
# Machine Learning Introduction

Machine Learning (ML) is a subset of Artificial Intelligence (AI)
that enables computers to learn patterns from data and make
predictions or decisions without being explicitly programmed.

## Types of Machine Learning

1. Supervised Learning:
Uses labeled data to learn the relationship between inputs
and outputs.

Examples:
- Linear Regression
- Logistic Regression
- Decision Trees
- Random Forest
- Support Vector Machines (SVM)

Used for classification and regression.

2. Unsupervised Learning:
Uses unlabeled data to discover hidden patterns and structures.

Examples:
- K-Means Clustering
- Hierarchical Clustering
- DBSCAN
- Principal Component Analysis (PCA)

Used for clustering and dimensionality reduction.

3. Semi-Supervised Learning:
Combines a small amount of labeled data with a large amount
of unlabeled data.

4. Reinforcement Learning:
An agent learns by interacting with an environment and
receiving rewards or penalties for its actions.

## Machine Learning Workflow

1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Train-Test Split
6. Model Selection
7. Model Training
8. Model Evaluation
9. Model Deployment

## Important Concepts

- Features: Input variables used for predictions.
- Labels: Expected output values.
- Training Data: Data used to train a model.
- Testing Data: Unseen data used to evaluate a model.
- Overfitting: Model performs well on training data but poorly
  on unseen data.
- Underfitting: Model fails to learn important patterns.
- Generalization: Ability to perform well on unseen data.
- Hyperparameters: Configuration values set before training.

## Regression and Classification

Regression predicts continuous numerical values.
Example: House price prediction.

Classification predicts discrete categories.
Example: Spam email detection.

Common evaluation metrics:
- Accuracy
- Precision
- Recall
- F1 Score
- Mean Squared Error (MSE)
- R-squared

## Model Optimization

Gradient Descent is an optimization algorithm used to
minimize a model's loss function.

Common optimization techniques:
- Stochastic Gradient Descent (SGD)
- Grid Search
- Random Search
- Cross-Validation

## Popular Machine Learning Libraries

- NumPy: Numerical computing.
- Pandas: Data manipulation and analysis.
- Matplotlib: Data visualization.
- Scikit-learn: Traditional machine learning algorithms.
- TensorFlow: Machine learning and deep learning.
- PyTorch: Deep learning framework.
- XGBoost: Gradient boosting.

## Applications of Machine Learning

- Recommendation Systems
- Fraud Detection
- Image Recognition
- Natural Language Processing

- Spam Detection
- Predictive Analytics
- Autonomous Vehicles

## Conclusion

Machine Learning enables computers to learn from data
and make intelligent predictions. It is widely used in
artificial intelligence, healthcare, finance, automation,
and modern software applications.
